# 📊 Sales Dashboard

An interactive and responsive **Sales Dashboard** built using HTML, CSS, JavaScript, and Chart.js. This project analyzes the Superstore sales dataset and presents important business insights through interactive charts, KPI cards, and filters.

## 🚀 Live Demo

**Live Dashboard:**
https://garimabajpai25.github.io/sales-dashboard/

---

## 📌 Project Overview

The Sales Dashboard provides a visual representation of sales performance and helps users understand important business metrics.

The dashboard allows users to analyze:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Monthly Sales Trend
* Sales by Category
* Sales by Region
* Sales by Segment
* Profit by Category
* Top 10 Products by Sales

Users can also filter the dashboard by **Region, Category, and Segment**.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/GarimaBajpai25/sales-dashboard.git
```

### 2. Open the project folder

```bash
cd sales-dashboard
```

### 3. Run the project

Open the project in **Visual Studio Code**.

Right-click on `index.html` and select:

**Open with Live Server**

The dashboard will open in your browser.
