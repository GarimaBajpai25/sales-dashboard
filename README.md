# 📊 Sales Dashboard

An interactive and responsive Sales Dashboard built using **HTML, CSS, JavaScript, and Chart.js**. The dashboard analyzes the Superstore sales dataset and presents important business insights through KPI cards, charts, filters, and product analysis.

## 🚀 Live Demo

[View Live Dashboard](https://garimabajpai25.github.io/sales-dashboard/)

---

## 📌 Project Overview

The Sales Dashboard provides an easy-to-understand visual representation of sales performance.

It helps analyze:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales Trend
- Sales by Category
- Sales by Region
- Sales by Segment
- Profit by Category
- Top 10 Products by Sales

The dashboard also provides interactive filters for **Region, Category, and Segment**.

---

## ✨ Features

### 📈 KPI Cards

The dashboard displays:

- 💰 Total Sales
- 📊 Total Profit
- 🛒 Total Orders
- 📦 Total Quantity

### 📊 Interactive Charts

The project includes:

- Sales Trend Chart
- Sales by Category
- Sales by Region
- Sales by Segment
- Profit by Category
- Top 10 Products by Sales

### 🔎 Interactive Filters

Users can filter the dashboard based on:

- Region
- Category
- Segment

The charts and KPI cards update automatically according to the selected filters.

### 📱 Responsive Design

The dashboard is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices
